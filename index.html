🐍 What is Python?

Python is a programming language — a way to write instructions that a computer can understand and follow. You type code in plain, almost-English words, and Python turns it into actions: calculations, websites, games, robots — anything.

Think of it like writing a recipe. The computer is the cook — it can't guess what you mean, but it follows your steps exactly, millions of times per second, without ever getting tired or bored.

👋 Your first program

That's it. One line. In most languages this takes 5 or more. Python respects your time. 💜
